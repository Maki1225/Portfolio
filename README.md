# My Portfolio

## 概要
自分のプロフィールや制作した作品、身につけたスキルを紹介するポートフォリオサイトです。

## 公開URL
https://Maki1225.github.io/Portfolio/

## 使用技術
- HTML
- CSS
- JavaScript

## 主な機能
- 自己紹介（ABOUT）
- 制作物の紹介（WORKS）
- スキルの紹介（SKILLS）
- お問い合わせ（CONTACT）
- カテゴリー別の作品表示
- 画像の拡大表示
- トップページへ戻るボタン

## ディレクトリ構成
```text
Portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── images/
```

## 制作目的
これまでに学習したプログラミングやWeb制作の知識を活用し、自分のプロフィールや制作実績を紹介するために制作しました。
