音声良否判定AI

Python / 機械学習 / 音声データ分析

Overview

音声ファイルを読み込み、音の特徴を分析して、 正常音と異常音を判定するアプリです。 音声データから特徴量を抽出し、機械学習を利用することで、 音声の良否を自動で判定できるように制作しました。

Development

音声データの分析には、MFCC、RMS、スペクトル重心、 ゼロ交差率の4種類の特徴量を使用しました。 抽出した特徴量をStandardScalerで標準化し、 KNN（K近傍法）を用いて正常音と異常音の特徴を学習させました。

また、正常音と異常音それぞれの特徴との距離を比較することで、 判定結果を表示する仕組みを実装しました。 複数の音声ファイルをまとめて選択できる機能や、 判定結果をCSV形式で保存できる機能も追加しました。

Technologies

Python / Librosa / NumPy / scikit-learn / Tkinter
