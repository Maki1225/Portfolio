PROJECT 01 / PYTHON

音声良否判定AI

Audio Quality Classification AI

作品概要

Pythonを使用して、音声ファイルの良否を判定するAIアプリを制作しました。 音声データを読み込み、特徴量を抽出して、正常音と異常音を分類します。

使用技術

  • Python
  • librosa
  • NumPy
  • scikit-learn
  • Tkinter

工夫したところ

MFCCやRMS、スペクトル重心、ゼロ交差率などの音声特徴量を利用しました。 StandardScalerでデータを標準化し、KNNによる分類を行う仕組みを実装しました。
